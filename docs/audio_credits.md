# JinHop audio

The game loads exactly these five files. Each one can be replaced by any
other file with the **same name and format (OGG Vorbis, mono)**; no code
changes are needed.

| File | Used for | Current file |
|---|---|---|
| `croak.ogg` | every frog hop (pitch varied 0.85–1.2x each time) and the win | placeholder, synthesised |
| `splash.ogg` | every hop (and a lower splash on undo) | placeholder, synthesised |
| `shake.ogg` | blocked tap: a soft thud, never harsh | placeholder, synthesised |
| `bloom.ogg` | win chime (rising pentatonic bells) | placeholder, synthesised |
| `ambient_loop.ogg` | soft pond ambience, looped (Music toggle) | placeholder, synthesised (31 s seamless) |

The placeholders were generated by `tool/audio/make_placeholder_sfx.py`
(numpy + scipy + ffmpeg). They are original works made for JinHop and are
released under CC0.

## Recommended CC0 replacements

All five sources below are listed as **CC0** on their pages (checked
27 Oct 2026; re-check before release). Crediting is optional under CC0;
the README credits section lists them once you swap them in.

| Target file | Source | Download | Which file to use |
|---|---|---|---|
| `croak.ogg` | "frog croaks" by EZduzziteh — https://opengameart.org/content/frog-croaks | croak_01.mp3 … croak_04.mp3 | the shortest, softest one (try croak_01.mp3) |
| `splash.ogg` | "6 short water splashes" by ezwa — https://opengameart.org/content/6-short-water-splashes | ezwa-water_splash.7z | the smallest, quietest splash in the archive |
| `shake.ogg` | Kenney "Interface Sounds" (CC0, 100 OGG files) — https://opengameart.org/content/interface-sounds | kenney_interfaceSounds.zip | a soft low "drop"/"click" sound (exact file names not listed on the page — audition a few) |
| `bloom.ogg` | "Pleasing bell sound effect" by Spring Spring — https://opengameart.org/content/pleasing-bell-sound-effect | pleasing-bell.wav | that file |
| `ambient_loop.ogg` | "Cathedral in the forest (ambient loop)" by congusbongus — https://opengameart.org/content/cathedral-in-the-forest-ambient-loop | forest_2.ogg | that file (seamless loop) |

### Converting

From the project root, with ffmpeg installed (mono, ~quality 4 keeps the APK
small):

```
ffmpeg -i croak_01.mp3      -ac 1 -c:a libvorbis -q:a 4 assets/audio/croak.ogg
ffmpeg -i <chosen_splash>   -ac 1 -c:a libvorbis -q:a 4 assets/audio/splash.ogg
ffmpeg -i <chosen_kenney>   -ac 1 -c:a libvorbis -q:a 4 assets/audio/shake.ogg
ffmpeg -i pleasing-bell.wav -ac 1 -c:a libvorbis -q:a 4 assets/audio/bloom.ogg
ffmpeg -i forest_2.ogg      -ac 1 -c:a libvorbis -q:a 3 assets/audio/ambient_loop.ogg
```

Trim long files so effects stay under ~0.5 s (bloom under ~2 s), for example
`-t 0.45`. Keep peak levels moderate: the game is meant to be calm.
